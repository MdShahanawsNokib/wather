# 🌤️ Live Weather App

A real-time weather forecast web application built using **React.js**, **CSS**, and **Node.js**. The app fetches current weather data using the **OpenWeatherMap API** and displays it with live clock, temperature, humidity, and animated icons. It also includes a fallback for users who deny location access, defaulting to **Dhaka, Bangladesh**.

> **Developed by Md Shahanaws Nokib, Bangladesh 🇧🇩**

---

---

## 🛠 Technologies Used

- **React.js** – Component-based UI
- **CSS** – Custom styling with animations
- **Node.js** – Backend support (if required)
- **OpenWeatherMap API** – Weather data source
- **react-live-clock** – Real-time clock integration
- **react-animated-weather** – Beautiful weather icons with animations

---

## ✨ Features

- 🌍 **Auto-detect user location** (with fallback to Dhaka if denied)
- 📅 Live **date and time display**
- 🌦️ Animated **weather icons**
- 🌡️ Real-time **temperature (°C) and condition**
- 📱 **Responsive UI** for mobile and desktop
- 🔁 Weather auto-refresh every 10 minutes
